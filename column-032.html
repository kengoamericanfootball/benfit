スタッフ不在の時間に事故が起きたら。
24時間ジムの安全配慮と防犯カメラ

低価格・24時間・無人時間帯という運営スタイルは、フィットネス業界の主流になりました。人件費を抑えられる一方で、「誰も見ていない時間帯」に事故や盗難が起きるという構造的なリスクを抱えます。深夜に一人でベンチプレスをしていた会員が下敷きになったら。ロッカーから財布が盗まれたら。規約に「一切責任を負いません」と書いてあれば安心でしょうか。そして、対策の要となる防犯カメラは、どこまで設置・利用してよいのか。無人運営に特有の法的リスクを、安全配慮と防犯カメラの2つの軸で整理します。

無人運営に固有のリスク

24時間ジムでは、スタッフがいない、あるいは極端に少ない時間帯が生じます。この時間帯に起こり得る問題は、大きく次の3つに整理できます。

  1. 事故——高重量のフリーウエイトで下敷きになる、急病で倒れる、器具の不具合で負傷する
  2. 防犯——ロッカーからの盗難、共連れによる非会員の侵入、盗撮、器物損壊
  3. トラブル対応の遅れ——上記が起きても、発見・対応が遅れる

いずれも「スタッフがいれば防げたかもしれない」という点で共通します。だからこそ、無人であることを前提とした代替措置が問われます。

事故安全配慮義務・施設管理義務。無人でも義務が消えるわけではない
盗難施設管理義務。ロッカー等の設備と管理方法が問われる
免責条項「一切責任を負わない」は消費者契約法8条で無効となり得る
防犯カメラ本人が判別できる映像は個人情報。防犯目的のみなら利用目的の通知・公表は不要だが掲示が望ましい
目的外利用防犯目的で取得した画像をマーケティング等に使うには、あらかじめ本人の同意が必要

整理のポイント

POINT

無人運営で押さえるべき要点は次のとおりです。

① 無人でも安全配慮義務・施設管理義務はなくならない。むしろ代替措置が問われる
② 「一切責任を負わない」条項は事業者に過失があれば無効となり得る
③ 防犯カメラは有効な対策だが、設置の掲示と目的の管理が必要
④ 防犯目的で撮った映像を他の目的に流用するには本人の同意が要る

ポイント①：無人でも安全配慮義務は消えない

施設を有料で提供する以上、事業者は会員の生命・身体の安全に配慮する義務を負います。スタッフを置かない選択をしたからといって、この義務が免除されるわけではありません。むしろ、「人による監視がない」ことを前提に、何を代わりに用意したかが評価の対象になります。

具体的には、次のような点が問題になり得ます。

  1. 器具の選定と安全装置 無人時間帯にセーフティバーのないベンチプレス台やフリーウエイトを自由に使わせる運用は、危険性が高い類型です。セーフティラックの設置、パワーラックへの置き換え、無人時間帯の一部器具の使用制限などが検討事項になります。
  2. 緊急時の通報手段 非常用ボタン、インターホン、警備会社との連携。倒れた人が自力で押せない可能性も踏まえ、遠隔監視や異常検知の仕組みも含めて考える必要があります。
  3. 点検・整備の記録 器具の定期点検と記録は、事故時に「必要な措置を講じていた」ことを示す資料になります（安全器具の整備義務が問われた事例は第2回コラム参照）。
  4. 利用者への注意喚起 無人時間帯は補助者がいないこと、高重量の単独使用を避けること、セーフティバーの使用を、掲示やアプリで具体的に伝える。抽象的な「自己責任」表記では足りません。

【「一切責任を負いません」では守られません】

会員規約に「施設内で発生した傷害・盗難について一切責任を負わない」と定めていても、事業者の債務不履行や不法行為による損害の賠償責任を全部免除する条項は、消費者契約法8条により無効となり得ます。器具の不備や管理の不十分さが事故の原因なら、規約の文言では免れられません（詳しくは第27回コラム）。

ポイント②：盗難と「共連れ」への備え

無人時間帯には、ロッカーからの盗難や、会員の入退店に紛れて非会員が入り込む「共連れ・すれ違い侵入」といった問題も生じます。鍵付きロッカーを設置していない低価格帯の店舗では、貴重品の管理が利用者任せになりがちです。

盗難については、施設側がどのような設備と管理を提供していたかが責任判断の分かれ目になります。貴重品ボックスを設置していたか、施錠可能なロッカーがあったか、注意喚起をしていたか、防犯カメラで抑止・記録できていたか。「盗難は自己責任」と掲示するだけでは、施設管理義務を果たしたことにはなりません（貴重品ボックスからの盗難が争われた事例は第6回コラム参照）。

共連れ対策としては、入退場管理システム（スマートフォンの認証、フラッパーゲート、共連れ検知）の導入が実務的です。非会員が施設内にいる状態は、事故が起きた場合の責任関係を複雑にします。会員規約に、共連れをさせた会員に対する措置（警告・利用停止・除名）を定めておくことも有効です。

ポイント③：防犯カメラは「設置すれば終わり」ではない

無人運営の生命線が防犯カメラですが、運用には個人情報保護法上の配慮が必要です。個人情報保護委員会のQ&Aによれば、実務上の要点は次のとおりです。

  1. 映像は個人情報 防犯カメラに記録された、本人が判別できる映像情報は個人情報に該当します。
  2. 防犯目的のみなら利用目的の通知・公表は不要。ただし掲示が望ましい 防犯目的のみのために撮影する場合、利用目的の通知・公表は不要とされていますが、防犯カメラが作動中であることを店舗の入口や設置場所等に掲示することが望ましいとされています。抑止効果の面でも掲示は有効です。
  3. 問い合わせ先の明示 個人情報についての問い合わせ先を入口や設置場所に明示し、詳細を掲載したウェブサイトのURLやQRコードを示すことが望ましいとされています。
  4. 顔識別機能を使う場合はさらに慎重に カメラ画像から顔特徴データを抽出して利用する場合は、利用目的をできる限り特定し、その範囲内で利用する必要があります。運用主体・利用目的・問い合わせ先等の掲示も求められる方向です。
  5. 目的外利用には本人の同意が必要 当初防犯目的で取得したカメラ画像や顔特徴データを、マーケティング等の商業目的で利用する場合には、あらかじめ本人の同意を得なければなりません。「混雑状況の分析に使う」「広告素材にする」といった転用は要注意です。

ポイント④：映像の第三者提供と肖像権

「迷惑行為をした会員の映像をSNSで公開したい」「他店舗に共有したい」——気持ちは分かりますが、慎重な判断が必要です。最高裁平成17年11月10日判決は、人はみだりに自己の容ぼう等を撮影されないことについて法律上保護されるべき人格的利益を有するとしました。撮影が違法となるかは、被撮影者の社会的地位、活動内容、撮影の場所・目的・態様・必要性等を総合考慮し、人格的利益の侵害が社会生活上の受忍限度を超えるかで判断されます。

加えて、顔画像等が個人情報データベース等を構成する個人データとして第三者に提供される場合には、原則としてあらかじめ本人の同意が必要です。警察への提出など正当な目的での提供は別として、SNSでの公開は避けるべきです。更衣室・シャワー室にカメラを設置しないことは当然として、着替えが映り込む角度にも配慮が必要です。

注意点：24時間ジム経営者が整えるべきこと

  1. 無人時間帯の運用ルールを作る 使用を制限する器具、セーフティの使用義務、緊急通報の方法。「無人だから何でも自由」ではなく、時間帯に応じたルールを定め、掲示・アプリで周知する。
  2. 緊急時対応フローを整備する 異常検知から警備会社・救急への連絡、駆けつけまでの手順と所要時間を明確にし、実際に訓練する。119番通報の判断基準も決めておく。
  3. 入退場管理と共連れ対策 認証システムの導入、共連れ検知、規約への措置規定。非会員の立ち入りを構造的に防ぐ。
  4. 防犯カメラの掲示・運用ルール 作動中である旨と問い合わせ先の掲示、録画データの保存期間・アクセス権限・削除ルール、目的外利用の禁止を文書化する。更衣室等への設置は行わない。
  5. 規約と保険を見直す 全部免責条項は無効となり得るため、免責の範囲を適法な形に修正する。あわせて施設賠償責任保険の内容（無人時間帯の事故が対象か）を確認する。

まとめ

  1. 無人でも安全配慮義務は消えない 人がいない前提で、器具・通報手段・注意喚起という代替措置を用意できているかが問われます。
  2. 「一切責任を負わない」では守られない 全部免責条項は無効となり得ます。規約ではなく体制で備えるべきです。
  3. 防犯カメラは掲示と目的管理をセットで 防犯目的なら通知・公表は不要でも掲示が望ましく、商業目的への転用には本人の同意が必要です。
